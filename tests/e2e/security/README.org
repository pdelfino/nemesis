#+TITLE: Security specs

One spec per row of the non-negotiables table in =SECURITY.org=. A row without a
failing spec is not a control yet, so the spec lands in the same pull request as
the code it guards.

* The harness

=_harness.ts= is the only way a spec here starts the app. It gives every spec
the same ground:

- =launchNemesis()= builds on a throwaway =userData= directory, launches the
  built app in =out/= with =NODE_ENV=test= so the main process resolves the
  deterministic Agent SDK mock in =src/main/agent/mock.ts=, hands back the
  cockpit window, and deletes the profile on =close()=. It passes Chromium
  =--use-fake-device-for-media-stream= so a camera or microphone request
  reaches the app's permission handler instead of stalling in the real
  audio capture stack on macOS (#49); the switch grants nothing. It writes
  the run's fixture certificate to a throwaway file and names it in
  =NEMESIS_TEST_CA=, the test-only trust anchor of #52, so a page served
  over HTTPS loads at all; =launchNemesis({ trustFixtures: false })= is the
  launch without it, for the spec that watches the certificate error be
  fatal. It also maps =nemesis.test= to loopback through
  =--host-resolver-rules=, port kept, so a spec has a plain =http= URL off
  loopback for the upgrade of #52 to act on.
- =openPageBuffer(url)= opens a URL in a real page buffer of the focused
  window (#119): the app's own hardened =WebContentsView=, with only the
  page-script door's preload (#130), built
  by =src/main/page-buffer.ts= and made current, through a door the main
  process installs under =NODE_ENV=test= only. It reports Chromium's refusal
  in =loadError= when the load never commits, and the page's =contentsId= as
  the main process's log lines name it. =openPageBuffer(url,
  { withPreload: true })= attaches the cockpit's preload to that hostile page
  instead, which is how =ipc-sender-validated.spec.ts= reaches a privileged
  channel from a web origin; no page buffer in the app ever gets it.
- =fixtureServer()= serves =fixtures/= on a random loopback port over plain HTTP
  and on another over HTTPS, with a self-signed certificate issued at test time
  by =_certificate.ts= (=node:crypto= signs but does not issue, so that file
  encodes the X.509 structure in DER by hand rather than adding a dependency).
  Both ports are printed when the server starts. A spec loads its hostile page
  from =secureUrl(...)=: the app is HTTPS-only off loopback (#52), and the
  launch trusts this certificate on purpose. =url(...)= is the plain loopback
  origin, allowed by the product rule; =upgradableUrl(...)= and
  =offLoopbackUrl(...)= are plain =http= on =nemesis.test=, on the HTTPS port
  and on the plain port, for the upgrade that lands and the one that cannot.

=example.spec.ts= is that shape end to end. Copy it.

* The fixtures

| File                | For                                                             |
|---------------------+-----------------------------------------------------------------|
| =node-probe.html=   | =process=, =require=, the module loader, the preload bridge     |
| =window-open.html=  | =window.open=, window features, =target=_blank=                 |
| =navigation.html=   | =location= set to =file:=, a =javascript:= URL and a top-level =data:= URL |
| =webview.html=      | a =webview= tag in markup and by script, =allowpopups= asked for |
| =download.html=     | a link, a scripted click and a navigation to =download.bin= (1 KB); a =mailto:= and a custom-scheme link |
| =injection.html=    | prompt-injection text, visible, hidden and in a comment         |
| =permissions.html=  | one button per device or data permission, outcome per =li=      |
| =pwned.js=          | a remote script the internal page's CSP must refuse to fetch    |
| =form-guide.html=   | a form with one field of each kind, filled secrets, an injected label and a counted submit (#94) |
| =page-door-pick.html= | rewritten =querySelectorAll=, =outerHTML=, =selectedIndex=, =dispatchEvent= and =Event=, an injected paragraph, a password field, a card expiry and a country dropdown that reports its events (#141) |
| =context-menu.html= | a plain link, and a link and a paragraph whose URL and text are code and an instruction, for the context menu (#180) |
| =external-editor.html= | a comment box, and a filled password and card number that =edit-with-external-editor= must refuse (#178) |

=user-pages.spec.ts= (#181) has no fixture file: its hostile page is the HTML
its own =init.ts= renders, served by the app on =nemesis://app/user/tools=.

The fixtures are hostile on purpose and harmless in fact: no fixture reaches the
network, and nothing outside this directory is served.

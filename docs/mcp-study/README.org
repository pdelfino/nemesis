tool surface against, records what the source actually does with the file
cited by name, and ends with what Nemesis shares with it and what it does
not. Nothing is ported: the studies feed ADR 0008 (#27) and the M3 and M4
issues. The shape follows =docs/nyxt-study/README.org=.

* Legend

yes / partial / no.

- *Technically* and *In plain words* open every table in this file and in the README: one line for an engineer, one line a 12-year-old would follow.
- *Keyboard* means a key model (every action bound, modal or Emacs-style), not just shortcuts.
- *Text UX* means the transcript or page state is a real text document you can search, copy and edit.
- *Agent* says how the agent is hosted.
- *MCP* says whether the app exposes its own commands as an MCP server (a plain MCP client gets "client").
- *Browser* means web pages inside the app.
- *Safety* means a stated, tested posture beyond the platform default.
- *Door* means user configuration or eval that changes the app at runtime.

* What the table says

- Nobody else has the five pillars together; since M4, Nemesis has all five. The two-pillar holders are agent-shell (keyboard, text, no browser and no door beyond Emacs), Glide (keyboard, door, no agent), BrowserOS (agent, browser, no key model), and the official app (cockpit, browser, no key model, no door).
- The "MCP" column is where Nemesis is nearly alone: only claude-code-ide.el, Vibe Kanban and BrowserOS expose anything to agents, and none exposes a full command table.
- The "Safety" column is where Nemesis and the official app are alone in having a tested posture; the agentic browsers lead with autonomy.
- The cockpit basics (sessions, worktrees, diff review) are owned by the orchestrators and the official app; Nemesis should not compete there, it should be the keyboard and text version of them.

What to take from Min: full-text history search, tasks as a grouping over buffers, and its password-manager bridge design as a study (not a feature, given the Brave rule). What not to take: the UI chrome running with Node and no context isolation.

* Goose against Claude Code in iTerm2 and Nemesis

Read on 2026-OCTOBER-20 for #183, where the full attribute table lives. In short:

- *Goose* wins on model choice (15+ providers), recipes with scheduling and headless runs, and community (Linux Foundation, weekly releases). Claude Code runs inside it only as an ACP provider, which has no session resume or fork yet, and its permission default is Autonomous.
- *Claude Code in iTerm2* is the baseline for daily feel: native features, subscription billing, but scrollback for text and no pages.
- *Nemesis* keeps the pillars neither has: a key model, the transcript as a text buffer, page buffers the agent reads as untrusted, and ask-by-default permissions with tested specs.
- Taken from Goose (decision A in #183): a fail-closed adversary reviewer behind the permission bridge, and recipes.
